# Adaptive control stays selective and autonomous

## Prompt

Implement a feature that touches a durable account schema and a background retention worker. One material
product-policy choice is still unspecified. Later, resume the prepared large run through an adapter that does
not support context rollover.

## Expected behavior

- Phase 1 runs the mechanical classifier after intake and elevates scope when the evidence requires it.
- The unresolved product-policy choice returns to Product Intake; Kimiflow does not invent the answer.
- Domain complexity and operational impact activate only with typed evidence and receive AC-linked Plan and
  Verification checks.
- A materially changed large phase context may create a digest-bound rollover receipt.
- The adapter's missing rollover capability records a bounded fallback and continues without a routine user
  confirmation.
- Lower-cost model roles remain on `top` until five comparable clean outcomes exist and are revoked after a
  failed outcome or HIGH finding.
- Vault results outside the project namespace never enter run context.
- Retention never archives the active run and processes at most one old terminal run.

## Must not happen

- The classifier answers the open product question or lowers an already declared scope.
- A small/no-pressure run receives rollover, Vault, retention, or extra review overhead.
- A stale rollover acknowledgement closes the pending receipt.
- A cheaper model is selected for critical-risk work.
- Missing provider, Vault, or adapter support creates a user gate.
