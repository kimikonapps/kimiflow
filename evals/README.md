# Measure the additional value

Compare the native host with the same host plus the minimal skill. Keep the model/effort, task,
starting revision, tools, permissions and total time/token budget identical. Count all worker usage.
Use disposable projects and define acceptance/regression checks before either attempt. Alternate the
order, prevent cross-arm reuse and assess results without revealing which arm produced them.

Record task/model, acceptance, remaining defects, user interruptions, elapsed time and actual usage
from the host. A small table and the original evidence are enough; do not build an evaluator platform.
Choose the acceptable quality/overhead trade-off before looking at the results. Measure Astra, Fable
and the actual local model separately. A few tasks are screening, not proof of general superiority.

Keep a feature only if its repeated benefit justifies its extra context, calls and maintenance.
If the native agent is sufficient, using it without Kimiflow is a valid result.

`outcome-comparisons.jsonl` and `evidence/outcome-comparisons/` preserve two historical development pilot
pairs. Both have recorded confounds; neither is primary evidence of a quality or cost advantage.
Their old schema/validator is retained at commit `c0849d69985074e9a8a7d5e5d5fac2cdd2f824b2`. No new model runs were performed
for the public release, and these old results must not be presented as measurements of it.
